# Identify AWS technical resources and AWS Support options

This task covers where to find official AWS knowledge, which AWS Support plan fits a need, how AWS Partners and AWS Marketplace extend what you can buy and build, and which AWS tools help you monitor an environment. Exam questions usually describe a need ("a team wants expert guidance", "a company wants to report abuse") and ask you to pick the right resource or plan.

## Key concepts

### Official technical resources

- **Documentation, whitepapers and guides** live on official AWS websites. AWS Whitepapers & Guides hold in-depth papers, and the AWS Architecture Center offers reference architectures and best practices.
- **AWS Blogs** announce new features and show worked examples.
- **AWS Prescriptive Guidance** provides proven strategies and patterns, for example for migration and modernization.
- **AWS Knowledge Center** holds official articles that answer frequent questions raised by Support customers.
- **AWS re:Post** is the community Q&A site where customers and AWS experts answer questions. It is free.

### AWS Support plans

All customers get **Basic Support**: 24x7 access to account and billing help, support forums, service health checks, documentation and whitepapers, and a limited set of Trusted Advisor checks.

Paid plans add technical support:

- **AWS Business Support+** adds 24x7 phone, web and chat access to Cloud Support Engineers, AI-powered contextual help, the full set of Trusted Advisor checks, the AWS Support API, third-party software support and fast response for business-critical system-down cases.
- **AWS Enterprise Support** adds a designated Technical Account Manager (TAM), the fastest response for production-critical cases, strategic business reviews and AWS Countdown event support.
- **AWS Unified Operations** targets mission-critical workloads, with a designated TAM and Domain Specialist Engineers, architecture guidance, critical workload reviews and runbooks.

Plan names and prices change, so check the plans page before relying on specifics. Developer Support is being phased out in favor of Business Support+.

### AWS Support Center

The **AWS Support Center** is the console location where you create and manage support cases and reach plan features. Basic Support customers can open account and billing cases there.

### Monitoring and health tools

- **AWS Trusted Advisor** inspects your account and recommends actions in areas such as cost optimization, performance, security, fault tolerance and service limits. The full check set requires a paid plan.
- **AWS Health Dashboard** shows events that affect your own AWS resources and accounts, such as scheduled maintenance or service issues.
- **AWS Health API** gives programmatic access to the same health information so you can feed it into your own tools.
- **AWS Trust and Safety team** receives reports of abuse of AWS resources, such as spam, malware hosting or attacks launched from AWS.

### Partners and Marketplace

The **AWS Partner Network** brings together companies that build on and sell with AWS. **Independent software vendors (ISVs)** build software that runs on or integrates with AWS. **System integrators (SIs)** design, migrate and run workloads for customers. Partner benefits include training and certification, events and volume discounts.

**AWS Marketplace** is a digital catalog where customers find, buy and deploy third-party software. It offers governance and control features and cost management tools, and charges appear in your AWS billing.

### Technical assistance from AWS

- **AWS Professional Services** is a global team of experts who work alongside your team on projects.
- **AWS solutions architects** give architecture guidance.

## Key terms

| Term              | Meaning                                                                  |
| ----------------- | ------------------------------------------------------------------------ |
| TAM               | Technical Account Manager, a designated guide for Enterprise-level plans |
| ISV               | Independent software vendor that sells software on or for AWS            |
| System integrator | Partner that designs, builds and migrates workloads for customers        |
| AWS Health API    | Programmatic access to AWS Health events                                 |
| AWS Countdown     | Event support for critical business events                               |

## Comparisons

| Need                                  | Best fit                            |
| ------------------------------------- | ----------------------------------- |
| Answers to a common how-to question   | AWS Knowledge Center or AWS re:Post |
| Open a case with an engineer          | AWS Support Center with a paid plan |
| Designated TAM                        | AWS Enterprise Support              |
| Find a third-party security appliance | AWS Marketplace                     |
| Outsource a migration                 | System integrator partner           |
| Hands-on expert project help from AWS | AWS Professional Services           |
| Event notices for my resources        | AWS Health Dashboard                |
| Cost-saving recommendations           | AWS Trusted Advisor                 |

## Exam tips

- "Designated TAM" points to Enterprise Support or higher, not Business Support+.
- Trusted Advisor recommends; AWS Health tells you about events affecting your resources.
- Abuse of AWS resources goes to the Trust and Safety team, not to Support cases about your own account.
- ISVs sell software; system integrators deliver services. Marketplace is where you buy ISV software.
- Basic Support does not include technical support cases.
